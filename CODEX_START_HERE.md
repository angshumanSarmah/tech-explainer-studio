# Codex quick start

**The authoritative step-by-step build guide is [EXECUTION_FLOW.md](EXECUTION_FLOW.md).**

1. Read [`AGENTS.md`](AGENTS.md), [`ARCHITECTURE.md`](ARCHITECTURE.md) and [`PROJECT_STATUS.md`](PROJECT_STATUS.md).
2. Open [`EXECUTION_FLOW.md`](EXECUTION_FLOW.md), copy its **First Codex message**, and run Phase 00.
3. For the next phase, use [`CODEX_PROMPTS.md`](CODEX_PROMPTS.md) to open the relevant `codex/NN-*.md` file and paste its one prompt.
4. After each phase, verify actual work and update `PROJECT_STATUS.md`. Update architecture only for actual changes. Stop for review; no extra SDD documents.

If you have already extracted an earlier archive, review [MIGRATION_FROM_PREVIOUS_ZIP.md](MIGRATION_FROM_PREVIOUS_ZIP.md) before replacing anything.
