# Handle a new requirement

```text
A requirement has changed. Compare the request against AGENTS.md, ARCHITECTURE.md, PROJECT_STATUS.md, the current codex phase prompt, docs/01-prd.md, docs/03-contracts.md and any relevant implementation. Identify which modules, contracts, tests, security boundaries and phases would change. Propose the minimal adjustment and an ADR only if an important architectural decision changes. Stop and ask for approval if the change materially affects scope, safety, compatibility or cost. Do not silently relax gates or copy external/proprietary code.
```
