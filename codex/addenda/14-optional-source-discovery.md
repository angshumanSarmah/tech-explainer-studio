# Phase 14 delta — Optional discovery, never a prerequisite

**Read alongside the existing `codex/14-autonomous-research-agent.md` if Phase 14 is explicitly chosen.**

The default studio workflow always accepts a topic **plus multiple user-provided URLs**. Phase 14 is optional and must not replace that workflow. Discovery, if implemented, only proposes a bounded list of candidate sources; the operator reviews/approves URLs before Phase 05 ingestion. No arbitrary repository clones, recursive website crawling, automatic acceptance of source claims or source-provided prompt execution.

Keep explicit cost/network consent and provider-independent/manual workflows. Do not block Phase 11C, 11D, 12, 09, 10 or 13 on this optional phase.
