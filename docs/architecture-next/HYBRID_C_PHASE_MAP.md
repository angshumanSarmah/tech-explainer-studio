## Cross-cutting acceptance rules

- Explicitly retain source/citation approval, GitHub file/commit selection and SSRF policies. Approval to fetch is not approval to publish or upload source contents to an AI provider.
- Draft script generated by AI stays draft; no model can approve facts/rights/quality or release. Persist exact script revision and used asset bytes/IDs/hashes.
- Model selectors are meaningful only for implemented adapters. Default option is manual/disabled when remote provider configuration unavailable. Director planning can be pre-approved for an explicit capped API budget; media generation requires separate later approval.
- Real VideoScript 1.2.0 remains authoritative. New media fields, if unavoidable, require deliberate backward-compatible versioning, not mutations to accepted 1.0.0/1.1.0/1.2.0 contracts.
- CLI and Vue invoke same services; users never need Codex to make per-topic videos.
- Every milestone STOPs for human review. Never start the next milestone merely because tests passed.
