# Tech Explainer Studio — Reviewed architecture direction and amendments

**Status: CONDITIONAL GO for the direction; amended [ADR-019](ADR-019-PROPOSED-composed-scenes.md) awaits final human acceptance.** The [existing architecture audit](ARCHITECTURE_VERIFICATION_2026-11-11.md) supplies source-code evidence and is retained unchanged; do not rerun it for these amendments. This file does not replace `ARCHITECTURE.md` or authorize Phase 11C implementation. Its conditional review decision supersedes the audit's earlier readiness recommendation, without changing its observations.

## Product goal
A user supplies a technology topic, **one or more user-approved official documents, GitHub references or technical articles**, audience, duration, creative instructions and an existing approved BrandProfile. Optional user notes remain untrusted evidence. Reuse Phase 05 ResearchBundle/ClaimLedger for bounded snapshots and claims. Content and Visual Director are logical planning steps within the existing Director and LLMProvider boundary; Visual Director emits **declarative data only** from the actual executable catalog. The existing Producer derives CompiledVisualPlan and renders through Remotion/Kokoro/FFmpeg. Phase 04 owns measured audio/frame/caption time; Phase 08 owns human factual, asset/media and exact-artifact release review.

## Non-negotiable boundaries
- **No AI coding at video-generation time.** No runtime generated JS, React/Three/SVG markup, executable expressions, dependency installation or source modifications. JSON-only candidate/revision; strict Zod and actual registry validation.
- Reuse Phases 01–08 and 11/11B; targeted backward-compatible integration fixes are allowed only when real repo evidence shows a gap. Preserve functioning 11B, which proved isometric 2.5D, not general GPU 3D.
- Generic composition is first class, but not unlimited. Specialized templates stay as optional registered components; unsupported educational intents cause structured diagnostics or an intentionally chosen truthful supported representation. No silent slide downgrade.
- ONE authoritative VideoScript authoring contract and ONE measured narration/timeline authority. The compiled render plan is internal derived output, not a competing authoring API. Scene overlaps and motion must preserve audio/caption timing and invalidation of output approvals.
- Add strict VideoScript 1.2.0; preserve historical 1.0.0/1.1.0 behavior and Director draft reads. New scene-level transition policies are opt-in through explicit revisions, including revisions using existing specialized visual types. Never add transition fields/defaults to old schema branches.
- Continuity has three bounded paths: existing intentional cuts, basic crossfade across compatible scene types **including specialized templates**, and matched-object handoff for compatible composed entities with stable IDs. Use the same composition/component handlers, total frame count and measured WAV/caption epoch. Export supported pairs and typed unsupported-combination diagnostics. ADR-019 defines the initial held-pose overlap and both-neighbor cache identity.
- Report every boundary's outgoing WAV inactivity, explicit padding, incoming inactivity, caption gap and exact input identities. A proposed 500ms review trigger highlights pauses; a human decides deliberate/unintended/unresolved through real narrated MP4 playback. No silent audio trimming/rewriting, fabricated word alignment or independent timer.
- Node/link/token is the initial slice, not the final product capability. Generic scenes reuse approved local assets and supported 2D/2.5D motion, depth and camera primitives. Acceptance includes a meaningful asset-backed generic composition, mobile framing/hierarchy/motion clarity and audible narration continuity. True GPU 3D remains unimplemented; no new per-topic handlers as the primary generation path.
- `ResearchBundle` source text, GitHub READMEs and technical pages are untrusted evidence, not AI system prompts or instructions. External URLs/asset licensing/claims need validation; retrieval does not equal authorization or truth.
- No hidden paid API calls, forced provider, automated publishing, invented human approval or claimed video-vision critique by text-only models.
- Repository roots/moving refs produce `selection_required`: explain missing file paths and immutable revision approvals, request exact operator-approved paths/full commit SHA, then ingest approved pinned files. Initial 11D may require the user to supply those URLs; no automatic repository inspection, cloning, recursive crawl, inferred file approval or fabricated pin. Optional Phase 14 topic discovery is separate.
- Actual schema/handler/catalog dispatch parity, semantic factual invalidation with unchanged narration, complete asset/artifact rights, both-neighbor invalidation and visual-only audio reuse are acceptance requirements. Enforce context byte/token/spend limits and freeze all grammar/implementation/prompt hashes before unseen holdout renders; disclose unsupported outcomes without silent fallback.
